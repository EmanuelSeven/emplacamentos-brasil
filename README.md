# Emplacamentos Brasil: painel de mercado

Este projeto organiza dados públicos de emplacamentos para acompanhar o mercado automotivo brasileiro. O autor trabalha na indústria de vidros automotivos, e nenhum dado interno da empresa será utilizado.

## Perguntas de negócio

- **Tendência:** emplacamentos mensais por categoria e acumulado de 12 meses.
- **Mix:** participação de cada categoria no total, ao longo do tempo.
- **Sazonalidade:** meses acima/abaixo da média do respectivo ano.
- **Juros × emplacamentos:** relação entre a Selic e os emplacamentos, com defasagem em meses.
